Hush

Private messaging with post-quantum encryption.

Download for Windows

Why an app and not a web client

A web client would mean this server hands you the code that does the encryption every time you open the page — so a compromised server could quietly serve a version that leaks your messages, and you would have no way to tell. The desktop app is installed once and verifiable, which is what makes “the server cannot read your messages” true rather than a promise.

How it protects your messages

Sessions are established with PQXDH — X25519 combined with Kyber-1024, so breaking it requires breaking both classical and post-quantum cryptography — and messages use the Double Ratchet, giving forward secrecy per message. This server only relays data it cannot read.

Message history is encrypted under a recovery key that never leaves your devices. Keep it: it is the only way to restore your conversations elsewhere.
