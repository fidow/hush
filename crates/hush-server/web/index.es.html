Mensajería privada con cifrado post-cuántico.

Descargar para Windows

Por qué una app y no un cliente web

Un cliente web significaría que este servidor te entrega el código que hace el cifrado cada vez que abres la página: un servidor comprometido podría servirte sin ruido una versión que filtre tus mensajes, y no tendrías forma de notarlo. La app de escritorio se instala una vez y es verificable, que es lo que hace que «el servidor no puede leer tus mensajes» sea un hecho y no una promesa.

Cómo protege tus mensajes

Las sesiones se establecen con PQXDH — X25519 combinado con Kyber-1024, así que romperlo exige romper a la vez la criptografía clásica y la post-cuántica — y los mensajes usan Double Ratchet, que da secreto hacia adelante en cada mensaje. Este servidor solo transporta datos que no puede leer.

El historial se guarda cifrado con una clave de recuperación que nunca sale de tus dispositivos. Consérvala: es lo único que permite recuperar tus conversaciones en otro sitio.
